# 평가셋 v1.2

교정본 FAQ(`data/faq_v2.csv`, 286건)를 검색 대상으로 하는 단일 평가셋이다. 1차 실험의 검색용(50문항)·생성용(60문항) 평가셋을 대체한다. 이 폴더의 `question_retrieval.csv`, `question_generation.csv`는 1차 실험 기록으로 남겨 둔다.

## 파일

| 파일 | 내용 |
|---|---|
| `evalset_v1.2.jsonl` | 본 평가셋 150줄. `status=keep` 148문항을 평가하고, `exclude` 2문항은 기록용으로 남긴다 |
| `evalset_out_of_scope_v1.2.jsonl` | 범위 밖 질문 10문항. 별도 묶음이며 Hit·MRR 계산에 넣지 않는다 |
| `CHANGES.csv` | 검수표 v1.1 대비 바뀐 값. 열: `question_id`, `field`, `before`, `after`, `reason`, `decided_by` |
| `p_column_approved_v1.2.json` | 검수표 P열 수정안 16건의 승인본(수정 후 문장과 사유) |

재생성: `python evaluation/scripts/build_faq_v2.py` → `python evaluation/scripts/build_evalset_v1_2.py`. 입력은 `handoff/`의 원천 파일이다.

검증: `python evaluation/scripts/validate_labels.py data/faq_v2.csv data/faq_merge_map.csv evaluation/inputs/evalset_v1.2.jsonl evaluation/inputs/evalset_out_of_scope_v1.2.jsonl` → 오류 0건.

## 문항 수

| 구분 | 문항 수 |
|---|---|
| 본 평가셋 (keep) | 148 |
| 제외 (exclude) | 2 — q012(q042와 같은 의도), q130(q047과 같은 의도. 정답 FAQ 94가 280으로 병합됨) |
| 범위 밖 | 10 (쉬움 2, 중간 4, 어려움 4) |

질문 번호는 q001~q153이며 q051, q059, q065는 v1.1 이전부터 없는 번호다. 148문항에서 1문항은 약 0.7%p다.

## 유형과 작성자 분포 (keep 148)

| 유형 | 직접 작성(v1.0) | 초안(Claude) | 합계 |
|---|---|---|---|
| 일상표현 | 27 | 17 | 44 |
| 복수근거 | 10 | 27 | 37 |
| 원문유사 | 11 | 23 | 34 |
| 조건형 | 9 | 24 | 33 |
| 합계 | 57 | 91 | 148 |

- `복수근거`는 필수 그룹이 2개 이상인 문항이다(2그룹 35, 3그룹 2). v1.1의 `복합질문` 중 필수 그룹이 1개인 10문항은 검수자가 다른 유형으로 재분류했다.
- `evidence_type`: single 111, multi 37.
- 대체 정답(한 그룹에 FAQ가 2개 이상)이 있는 문항은 16개다. 그 FAQ 본문만으로 해당 부분에 완전히 답할 수 있을 때만 대체 정답으로 인정했다.

## 라벨 형식

- `required_groups`: 그룹 사이는 AND, 그룹 안은 OR. 모든 그룹에서 FAQ가 1개 이상 Top-K에 들어야 Hit@K = 1이다.
- `supporting_faq_ids`: 보조 FAQ. 어떤 지표에도 넣지 않는다.
- 연번은 `faq_v2.csv` 기준이다. 병합으로 제거된 94(→280), 152(→250)와 본문이 없어 제외한 99는 라벨에 쓰지 않는다.

## 작성과 검수

- 질문·기준 답변 작성(`author`): 검수표 `출처` 열 값. `직접 작성(v1.0)` 57문항, `초안(Claude)` 91문항(keep 기준).
- 라벨 초안(`label_author`): Claude가 썼다. 라벨은 검수자가 확정했다.
- 검수자: 1인(본인). `reviewer=본인`은 검수자가 결정을 직접 입력한 문항(54문항)이다. 결정표 `1_필수라벨`, `2_기준답변`, `3_유형재분류`, `5_기타확인`, 검수표 P열 수정안이 해당한다. 나머지 문항의 `reviewer`는 빈 값이다.
- 범위 밖 10문항은 검수자가 모두 수락했다(`reviewer=본인`).
