# FAQ 데이터

국가공무원 채용시험 FAQ(공공데이터)의 원본, 교정본, 검색 대상 파일과 변경 내역이다. 작성일 2026-11-12.

## 파일

| 파일 | 행 수 | 역할 |
|---|---|---|
| `faq_raw.csv` | 289 | 공공데이터 **원본**. 1차 실험(2026.06~07)의 검색 대상. 변경하지 않는다 |
| `faq_corrected.csv` | 289 | 원본의 본문 밀림·공백을 바로잡은 **교정본** |
| `faq_v2.csv` | 286 | **검색 대상**. 교정본에서 중복 2건 병합, 본문 없는 99 제외, 15 반복 본문 정리. 인덱스(`src/indexing.py`)와 평가셋 정답 번호의 기준 |
| `faq_merge_map.csv` | 2 | 병합표(제거한 연번 → 남긴 연번) |

열은 FAQ 세 파일 모두 `연번`, `제목`, `본문`이다. 연번은 다시 매기지 않았다. 그래서 `faq_v2.csv`의 연번에는 94, 99, 152가 빠져 있다.

파일 이름 이력: `faq_raw.csv`는 2026-11-12 이전 `faq.csv`, `faq_corrected.csv`는 `faq_v1.1.csv`(그 전 오타 `fag_v1.1.csv`)였다. 태그 `experiment-v1`, `evalset-v1.2`, `evalset-v1.3`은 예전 이름 시점에 고정돼 있다.

## 원본(faq_raw.csv) → 교정본(faq_corrected.csv) 변경

교정은 claude.ai 채팅 작업에서 했다. 교정본의 원천은 구글 시트 '인사혁신처_사이버국가고시센터 국가공무원 채용시험 종합안내(FAQ)_20260320'이다. 아래 내용은 2026-11-12에 두 파일을 행 단위로 비교해 확인한 것이다. 행 수(289)와 연번은 같다.

| 구분 | 연번 | 원본의 문제 | 교정본 |
|---|---|---|---|
| 본문 밀림 | 100~200 (101건) | 본문이 한 칸씩 위로 밀려 있었다. 원본 99~199행의 본문은 실제로는 그다음 연번 질문의 답이었다. 예: 원본 99(사관학교 중퇴)의 본문은 100(대학 소재지 이전)의 답 | 각 본문을 제 연번으로 옮겼다. 교정본 k행 본문 = 원본 k−1행 본문 |
| 본문 유실 | 99 | 제 본문이 없었다. 99행에는 100의 답이 들어 있었다 | 빈 본문. faq-v2에서 검색 대상에서 제외 |
| 본문 대체 | 200 | 원본 200행 본문은 같은 공고문 안내의 옛 표기판이었다(사이트명 '사이버국가고시센터') | 원본 199행 본문('국가공무원채용시스템' 표기)으로 대체. 원본 200행 본문은 교정본에 남지 않음 |
| 공백 | 제목 16건(4, 27, 44, 48, 56, 79, 99, 101, 178, 204, 211, 223, 228, 236, 257, 258), 본문 2건(98, 259) | 앞뒤 공백 | 공백 제거. 글자 변경 없음 |
| 본문 반복 | 15 | 같은 본문이 두 번 이어짐 | 교정본에도 그대로 있음. faq-v2에서 한 번만 남김 |

영향: 1차 실험은 원본으로 진행했다. 그래서 연번 100~200의 FAQ는 제목과 본문이 맞지 않는 상태로 검색되고 생성 근거로 쓰였다. 1차 결과를 다시 쓰지 않는 이유 중 하나다(`archive/experiment-v1/README.md`).

## 교정본(faq_corrected.csv, 289건) → 검색 대상(faq_v2.csv, 286건) 변경

| 연번 | 처리 | 사유 | 결정 근거 |
|---|---|---|---|
| 94 | 제거 (280으로 병합) | 280과 제목이 같고 본문이 거의 중복됨 | `faq_merge_map.csv`, 결정표 `5_기타확인` "FAQ 병합 = 확정" |
| 152 | 제거 (250으로 병합) | 250과 제목이 같고 본문이 거의 중복됨 | 위와 같음 |
| 99 | 제거 (검색 대상에서 제외) | 교정본에 제목만 있고 본문이 비어 있음 | 결정표 `5_기타확인` "FAQ 99 처리 = 검색 대상에서 제외" |
| 15 | 본문 중복 제거 | 같은 본문(229자)이 두 번 이어져 있었음(458자 → 229자). 앞 절반과 뒤 절반이 정확히 같음을 확인한 뒤 앞 절반만 남김 | 결정표 `5_기타확인` "FAQ 15 본문 중복 = 확정" |

나머지 285건은 교정본과 글자 하나까지 같다.

- FAQ 99는 병합이 아니라 제외이므로 `faq_merge_map.csv`에 넣지 않았다. 평가셋 라벨 검증(`validate_labels.py`)은 `faq_v2.csv`에 없는 연번을 "없는 FAQ"로 처리한다.
- FAQ 5와 250은 근접 중복이지만 병합하지 않았다. 평가셋에서 대체 정답(`required_groups`)으로 처리한다.

## 결정 출처

- `5_기타확인` 시트의 결정은 사용자가 구글 시트 `검토결정표_v1.2`에 입력했다(2026-11-12 확인). `evaluation/evalset/v1.2/label_decisions.xlsx`에는 이 시트가 비어 있다. 1~4번 시트는 두 파일이 같다.
- 결정 입력: 본인. 처리 스크립트 실행: Claude Code.

## 재생성

`python evaluation/scripts/build_faq_v2.py` (입력: `faq_corrected.csv`, `faq_merge_map.csv`)

## 파일 형식

`data/faq_raw.csv`와 같게 UTF-8(BOM 포함), CRLF 줄바꿈, 필요한 칸만 따옴표로 저장했다.
